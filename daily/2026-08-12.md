### Key Takeaways:
- ST_Distance returns degrees if you use geometry with SRID 4326; to get meters, cast to geography
- Always clarify units in both your code and your AI prompts
- Using ST_DWithin with geography casting is the pattern for accurate distance queries

### Sample Prompt Used:
"Write a PostGIS query to find the names of all parks within 2 kilometers of a specific school. Tables: schools(id, geom), parks(id, name, geom). Both tables are in EPSG:4326."
Sample Query:

### SELECT p.name

```
SELECT p.name
FROM parks p
JOIN schools s ON s.id = 123
WHERE ST_DWithin(s.geom::geography, p.geom::geography, 2000);

```
